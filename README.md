# Node.js Öğrenme Projesi

Bu depo, Node.js öğrenme sürecimde geliştirdiğim örnek projeleri ve kodları içerir.

## İçerik

- Film Yönetim API'si
- Basit HTTP istekleri örnekleri
- Frontend entegrasyonları

## Kurulum

```bash
# Depoyu klonlayın
git clone https://github.com/erdemCnl/nodejsLearn-2.sinif-.git

# Proje dizinine gidin
cd nodejsLearn-2.sinif-

# Bağımlılıkları yükleyin
npm install
```

## Kullanım

Örnek projeler ayrı HTML ve JavaScript dosyaları olarak organize edilmiştir. Her bir örneği tarayıcınızda açabilir veya Node.js ortamında çalıştırabilirsiniz.
